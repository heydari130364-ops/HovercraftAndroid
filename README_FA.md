# برنامه اندرویدی کنترل هاورکرافت با USB Serial

این پروژه برای Android Studio است و دستگاه‌های USB Serial مانند CH340/CH34x را پشتیبانی می‌کند.

## ساخت برنامه
1. Android Studio را نصب کن.
2. گزینه Open را بزن و پوشه HovercraftUsbAndroid را انتخاب کن.
3. اجازه بده Gradle Sync تمام شود؛ در صورت درخواست، Android SDK Platform 35 را نصب کن.
4. گوشی را با کابل USB-C به برد وصل کن و برنامه را اجرا کن.
5. درخواست اجازه USB را قبول کن.
6. برای ساخت APK از Build > Build APK(s) استفاده کن.

## پروتکل
سرعت 9600، قالب فرمان `<speed,angle>\n`، مانند `<50,90>`.
سرعت 0 تا 255 و مقدار زاویه 0 تا 180 است. زاویه فعلاً فقط عددی است؛ این کد سروو یا مکانیزم فرمان را کنترل نمی‌کند.

## ایمنی
دکمه توقف اضطراری در این نسخه یک فرمان نرم‌افزاری `<0,90>` می‌فرستد و توقف ایمن سخت‌افزاری را تضمین نمی‌کند. تا زمان نصب درایور موتور و منبع تغذیه مناسب، موتور واقعی را وصل نکن.
